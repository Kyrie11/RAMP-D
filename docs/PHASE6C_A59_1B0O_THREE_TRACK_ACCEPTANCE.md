## 1. 数学主线：A59/1b-1 的入口子阶段

### 1.1 上轮问题复核

A67 实际字节哈希保证 `SHA256(raw)==declared` 和 `(world,start,end,control,role)` 匹配，但是**不对 raw.body 的数学声明进行独立复算**，且尚无全部隐藏后继和接受任务尾策略的外部证明。A68 的精确仿射区间和单资源状态机各自测试通过，也不能自动说明它们引用的是**同一时间片、同一个隐藏世界与完整初始占用支持**。

### 1.2 本轮实际新增

- `a69_hybrid_joint_reference.py`：将精确 `x'=v, v'\in[a_-,a_+]` 的 A68 reference 与同片 `ZoneTick` Guard 串接，强制两隐藏世界每片都有记录；每世界**必须显式声明初始占用**；时间点、公共控制一致；无匹配 ACK、容量、方向、进入/停留/退出、区间缩小都拒绝。返回 `CONDITIONAL_JOINT_TOY_MODEL_REPLAY_PASS`，绝不 `CERTIFIED`。
- `a69_affine_artifact_semantics.py`：从 `rampd.a67.context_artifact.v1` 的 *native_tube 角色文件*反序列化严格有理数区间，对模型 `exact_affine_xdot_v_vdot_a_v1` **重放真实有理数方程**，同时核对各文件 SHA-256、协议合同原始字节 SHA-256、世界／时间／公共控制身份。不只是检查哈希相等；即使攻击者更新一份错误区间的哈希，也会因数学上低估而被拒绝。

### 1.3 范围限制与下一阶段

重放只证明约束严格声明的一维仿射模型，而非真实车辆、CARLA 或 Native MPFR/Picard。A59/1b-1 正式验收仍需：时间分片右连续规则生效、每片原生连续 reachable tube、全部 actor 包络、资源完整多边形+冲突图、完整 Guard/ACK 实效、公共观测支持全集、`Pre_obs` 非预见性和接受任务尾的严格下降 rank。

核心闭环必须满足：

\[
\forall\omega,\ i,\quad Z^{\omega}_{i+1,\mathrm{start}}\supseteq
\operatorname{Post}^{+}_{\rm Native}(Z^{\omega}_{i,\mathrm{start}},u_i),\qquad
\forall o:\ \operatorname{Post}_{\mathcal P}(B,u,o)\subseteq
\underline{\mathcal W}^{SC}_{h-1}.
\]

零认证漏洞约束：已认证的有限时间接受策略才能构成 `K_term^SC`，不能把停止安全等同完成任务。

## 2. 物理主线：A5/3c 的去混杂设计

### 2.1 用户实测事实

- CARLA `0.9.16`、`Town06_Opt`、`vehicle.tesla.model3`、单独时钟、20 Hz。
- 三个不同 actor ID `121/122/123`；各 66 帧；`combined_brake_fraction=0.45`，`steer_fraction=0.03`，`steer_pulse_s=0.15`。三次最大纵向减速度幅值 **26.9265646570 m/s²**，最大横摆速率 **0.0572846533 rad/s**，归一化轨迹相同。
- 该异常远高于简化轮最大制动扭矩／轮径／质量的近似量级（约 4.10 m/s²）。比较模型本身**不是 CARLA 物理引擎的上界**，不能据此断定模拟器错误；仍需检查完整 `PhysicsControl`、刹车/发动机/阻力/轮胎模型、控制触发时序和帧差分。确定性重复不构成扰动支持或可靠误差集合。

### 2.2 本轮实际新增

- `a69_physical_factors.py`：严格读取三档 `0.15/0.30/0.45` 的真实*原始* JSON。要求每档声明与实际执行的制动一致，转向脉冲、地图及选点、OpenDRIVE 哈希、天气、物理参数、速度和仿真步长等非制动因素保持一致；缺失任何档、重复原始文件、混合环境、控制值不一致、触发速度不匹配一律 `REVIEW`。
- 修复 `a68_waymax_action_contract.py` 之前仅检查 `v(dt)>=0` 的漏洞：`v(t)=v_0+a_0t+jt²/2` 可以在时步内部为负，而两端为正；新版精确检查 `t*=-a_0/j` 落在步内时的速度极小值。若发生未建模的停车反向，则 fail-closed。

### 2.3 可检验的单因素方案

阶段 1：5 m/s、同一 Town06 路段及天气/轮胎配置、固定转向 `0.03` / 脉冲 `0.15 s` / 20Hz，仅改变联合制动 **0.15、0.30、0.45**，每档先 1 次做模型定位。阶段 2：确认所有档均采集有效后每档至少 3 次，并用独立观测留出验证，不把确定性一致误称概率鲁棒界。阶段 3：速度 5/10/15 m/s、摩擦、坡度、执行延迟、physics settings 做一次仅变一个主因素的分层网格；残差支持可验证后才能回馈 MPFR 车辆误差外包络。

Waymax 的当前位置/后轴参考点、左右手系、横摆/曲率、连续 jerk/转向速率与离散加速度/曲率适配必须单独审计；SUMO 九组丢失控制汇总需要新工作目录补跑，逻辑通道不可冒充物理单车道。CARLA/SUMO 联合需独立地图配准、唯一时钟和唯一车辆/信号控制权。
