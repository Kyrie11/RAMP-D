# A75 head-specific acceptance contract (proposal; implemented subset below)

One sample may carry several evidence domains, but masks refer to **individual targets**, not a global certification bit. `training_allowed` also requires split provenance, train-only fitting, no future leakage and a fixed scenario-family split. Unknown is not zero. A hash is identity, not authority. Do not combine weak event category with physical effectivity, sampled geometry with continuous exclusion, or model counterfactuals with actual human responses.

| Head | Target / admissible source | Required acceptance before enabling |
|---|---|---|
| event | type, source/scope, resolved rule, activation/effectivity interval; protocol logs; 511NY/WZDx only reported fields | clock semantics and units, rule/authority/version consistency, physical onset distinct from issue/receipt, interval censoring with justified endpoints; no synthetic times marked real |
| joint | factual WOMD/AV2 trajectory conditioned on logged ego path surrogate; separately paired closed-loop model | official scenario+record digest, split, valid masks, history boundary; same actor IDs, controls, initial/seed/protocol in pair, A/AA negative and informative intervention, future-route privilege separate, future-only ADE and interaction/kinematic/map metrics |
| occupancy | sampled entry/stay/exit and independently swept interval occupancy | geometry/reference/clock/roster/dynamic lifecycle, legal resources independently mapped, exact sampled polygon reconstruction; continuous claim requires proven tube; possible vs definite occupancy separate; first/last censoring; capacity/conflicts; shared lane co-sim separate |
| observation | detection/occlusion, awareness proxy, publication/receipt, silence censoring | aligned sensor frames and camera geometry, visibility not awareness, detector vs ground-truth separate, message IDs, send/receive/log completeness, drop/late cases; never infer absence from silence without protocol guarantee |
| viability | certified policy positive; exhaustive finite-model negative | same model/protocol/support/action class/goal/time, independent replay all branches, exact finite negative only, candidate failure or budget exhaustion UNKNOWN |
| margin | conservative continuous lower bounds and pairwise ranking | all hard feasibility predicates separately discharged, same scales and supports, interval proof, no single sampled margin or empirical brake promoted |
| deadline | Ddefer, Dstart, Tobs+, ICG interval | same candidate prefix/context, exact small scheduler or validated dynamic controllability, deadline/clock uncertainty, lower/upper evidence, unresolved signs masked |
| causal | exogenous invariance and mediated actuated event response | same initial state, exogenous realization and protocol randomness, action intervention logged, controller/flow mediation, pair plus A/AA; null effect retained only when intervention/exposure valid; model labels not real causal identification |

A75 implemented: actual WOMD factual validation rows (5 scenarios, 1708 target knots, 15 future-born actor IDs excluded and reported; training rows 0); actual SUMO sampled two-strip evaluation rows (9000, no continuous/ACK mask); all other heads are not activated. Train eligibility for factual rows requires matching independent split manifest. This is not a complete multi-head PyTorch loader or trained model. A separate global scene-family manifest is still required. ROADWork 65/4 and 511NY 1500 text rows remain separate auxiliary evidence, not full event/observation targets.
