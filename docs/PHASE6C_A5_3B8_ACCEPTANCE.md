## 1 本轮目标与状态

1. **先复核** A57 在服务器上的真实通过情况，不能沿用上一轮过时判断。
2. **修复数学歧义**：离散物理 Post 能产生下一时刻支持，不等于 SafeTube，更不等于任务 SC 或终端尾策略。
3. **提供精确 jerk 参考**：支持参数化初始加速度、显式延迟、解析分段，明确拒绝尚不支持的短速度三角制动；不做隐藏速度截断。
4. **守住封闭物理证据**：提供真实仿真同步帧、障碍物 actor 身份/位姿/车辆侵入检查，无法从离散观测推断连续存在。

6. **为 CARLA/SUMO 接入做准备**：纯读取元数据/时钟预检和车辆参数采集，不声称已经完成部署、同步、完整控制权或碰撞证明。

## 4 本地实测测试与失败案例

- `python scripts/validate_a58_pure.py`: **19 passed**（独立纯 Python 参考和契约测试）。
- 511NY/ROADWork/Waymax/SUMO 的**既有上传结果**已重新解码，并非重新运行这些模拟器。ROADWork 原始 `annotations.zip` 经实际读取成功导出69份组不重叠图像模板，文件写到会话产物中。
- A58 原生安全测试5项已写完，但当前容器缺 MPFR/GMP C++ 开发头和本地 Waymax/SUMO/CARLA；尚未本地运行新原生回归，**服务器必需验证**。
- 发现并修复：短速度停车模板会在第一段先产生负速度 → 在执行前解析判断 `UNKNOWN_TRIANGULAR_STOP_PROFILE`；期望舒适制动超执行器减速度极限 → 新增硬拒绝；旧 interlock 在 DRAIN 期间因障碍物异常把退出权限同时收回 → 改为仅撤销新进入、保留存量车辆退出权。
- 发现并修复：ROADWork 数据导出原先会触发包级 MPFR import，改为纯数据 shell，数学正式验收**仍必须**加载原生 MPFR。
- 仍未解决：真实道路曲线 IDM gap；SUMO 新压力工况；匿名真实车辆的轴距、后轴 offset、轮胎摩擦/最大制动/执行器延时；跨帧障碍物完整覆盖；一般资源拓扑与完整 SC。

## 5 安全性声明范围

`CONDITIONAL_EGO_AVOIDANCE_PASS` 仅证明给定的已完整**声明**参与者集合、矩形限制资源、动力学/扰动参数和全时域分段外包络中的连续避障、车辆数值边界；其中资源目前必须证明**无侵入**才能通过。并不证明实际上对整个真实世界 actor 群完成枚举、真实传感器覆盖、合法资源穿越、完整观测/延迟协议、任务完成性及终端尾策略。任何上述条件未建立均为 `UNKNOWN`。

严格遵守论文：只有完整声明支持、观测条件下的公共控制和接受的有限终端 rank 策略都通过独立验证器，才能对相应模型返回 `CERTIFIED`。训练标签正负/未知也不可将优化失败或单个候选反例当作全局负例。
