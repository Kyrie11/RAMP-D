# Supervision source contract for the eight paper losses

The `supervision_inventory(scene)` API (schema `rampd.phase6c.supervision-inventory.v1`) is **only an availability report**, not a label generator. An unavailable signal must be masked; do not populate with zeros that would be interpreted as negative labels. It follows the latest TeX `tab:supervision` and uses each source only for labels it truly provides.

| Loss | First usable real-dataset source | Exact masked / generated remainder |
|---|---|---|
| `L_joint` | WOMD Scenario tracked 2D positions, velocities, heading and masks; AV2-MF positions, velocity, heading, `FOCAL_TRACK`/`SCORED_TRACK`; `sdc_track_index` in WOMD, `AV` ego vs focal track in AV2 | **Only logged-action** conditional trajectory. For alternate ego prefixes use paired simulator interventions with shared external seed; otherwise model uncertainty using independent reachable tubes. Future-only actors should not be mislabelled as observed-history responses. |
| `L_event` | WOMD `dynamic_map_states` traffic-light lane state provides **auxiliary signal-state labels** only; AV2-MF has no signal-controller temporal labels | For actual exogenous/actuated rule events log source, scope, activation/effectivity windows and resolution in SUMO/CARLA or explicit symbolic protocol; missing event times get interval-censored targets, not fabricated exact timestamps. |
| `L_occupancy` | Compute a weak geometric entry/stay/exit label from valid box centres/headings/dimensions and vetted road-resource polygons; WOMD has object dimensions per valid state, AV2-MF needs explicit class geometry envelopes | Only when both shape and map geometry are valid. If geometry uncertain, retain an uncertainty envelope; never use point-centre-in-polygon as a footprint proof. Resource capacity/legal permission needs a separate symbolic product-graph model; continuous-time margins need a reachability certificate. |
| `L_observation` | Neither benchmark's `observed` history bit means the vehicle or other agents actually saw a sign or received a message | CARLA visibility/occlusion and sensor production/delivery times; SUMO/CARLA issue/receipt logs; explicit censoring for silence. Do not infer hearing from traffic-state ground truth. |
| `L_viability` | No direct labels in WOMD/AV2-MF | Positive = policy accepted under complete finite abstract game plus audited physical/protocol/terminal proofs; negative = complete finite class proved infeasible. Timeout, solver `UNKNOWN`, or counterexample to one candidate are **masked**. |
| `L_margin` | No direct certified label in WOMD/AV2-MF | Generate an outward-rounded lower bound using validated full-support reachable tubes and resource/footprint constraints, with matching support and action digests. Pairwise comparisons only for common initial support. |
| `L_deadline` | No direct certified label in WOMD/AV2-MF | Solve exact small-instance conditional controllability with protocol effective intervals, reachable tubes, option latest-start and guaranteed observation-separation time; **same public prefix** for both terms of `ICG`. Mask unresolved instances. |
| `L_causal` | Observational WOMD/AV2 trajectories are not paired interventions | Paired simulator experiments holding initial state, external rule seed, and protocol realization fixed, vary only candidate ego prefix. Exogenous event predictions should remain invariant to intervention; actuated event effects go through flow and controller dynamics. |

**Split control:** training targets only from training trajectories, validation labels only offline and never supplied to model inputs; test future withheld even if any file accidentally carries it. No official challenge mAP, minADE@K, occupancy, or safety metrics are claimed by the CV debug baseline. Maps and vehicle reference points must be consistent before geometry labels can be generated.
