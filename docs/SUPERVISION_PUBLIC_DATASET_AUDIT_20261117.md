# Supervision sources for the latest manuscript (8, not 9)

**Primary data**: WOMD v1.3.1 Scenario and AV2 Motion Forecasting. The proposals below distinguish *actual recorded observation*, *derived weak annotation*, *simulated intervention*, and *formal proof artifact*; these are NOT interchangeable in the training/test tables.

| Target | Already available in WOMD/AV2-MF | Public complement (use case, limitations) | Must synthesize/prove |
|---|---|---|---|
| `L_joint` | Actual-trajectory multiagent 2D kinematics + validity masks; WOMD actor box dimensions | nuPlan with reactive closed-loop simulated agents; Waymo Open Sim Agents examples (simulator training, not unseen action ground truth) | Paired alternate-ego response in simulator; no legitimate real-world counterfactual labels from a single log |
| `L_event` | WOMD traffic-light lane state timestamps (auxiliary, not issue/effectivity clock); AV2 map semantic labels | nuPlan light state, **inferred from behavior** so noisy; SUMO TraCI traffic light state changes | Explicit rule source/scope, event activation, effectivity and controller authority as protocol logs |
| `L_occupancy` | WOMD box geometry + map features; AV2 Motion positions/headings and lane/crosswalk map | AV2 Sensor cuboids for *different* logs; nuPlan object tracks/maps | Resource polygon intersection in calibrated coordinates; AV2 MF shape unknown implies masked shape supervision, not imputed hard certificate |
| `L_observation` | No true ego sensor awareness/receipt/silence labels in either MF dataset | AV2 Sensor (9 cameras/LiDAR + ego poses) and Waymo Perception (sensor and boxes) enable weak visibility/occlusion geometry | Sensor frustum/raycast + timestamped production/delivery + right-censored silence with known delivery guarantees |
| `L_viability` | None | nuPlan scenario tools can propose/benchmark candidate tasks; do not treat log success or simulator heuristics as global feasibility | Complete finite-game oracle for negative *only within declared class*; proof-carrying policy for positives; UNKNOWN masked |
| `L_margin` | None | Model and map/box labels are ingredients, not certified margins | Verified continuous swept reachable tube + robust resource constraints; conservative lower bounds only |
| `L_deadline` | No reliable decision latest-defer/guaranteed-observation label | nuPlan scenario timeline may suggest nominal opportunities but no robust deadline guarantee | Same public-prefix CCG/ICG, STNU controllability and certified temporal windows |
| `L_causal` | Only observational trajectories | Waymo Sim Agents and nuPlan reactive simulator can help form *proposed* interactive responses | Paired CARLA/SUMO experiments fixing exogenous realization and initial support, random seeds, protocol, clocks; compare intervened ego prefix, NOT paired real labels |

**Recommendation**: retain causal factorization as a structural inductive bias and counterfactual *simulated consistency* loss. Do not discard it solely for lack of real logged counterfactual outcomes, and do not overstate simulator counterfactual fidelity. Train `L_joint` on factual observations first; keep `L_causal` masked until a stable seeded paired-simulation protocol exists. Use explicit domain/source indicators to avoid treating simulation-generated counterfactuals as measured real-world truth. Build deadline/viability/margin supervision only from formal generators.

**Potential public sources (check license and matching task)**: [WOMD v1.3.1](https://waymo.com/open/data/motion/), [Waymo E2E](https://waymo.com/intl/en-ca/open/data/e2e/) for route instructions and rater feedback (not certified routes), [Waymo Open Sim Agents](https://waymo.com/research/the-waymo-open-sim-agents-challenge/), [nuPlan](https://www.nuplan.org/) for reactive simulation/planning, [AV2 Sensor](https://argoverse.github.io/user-guide/datasets/sensor.html) for visibility weak labels. AV2 Sensor and AV2 MF are distinct corpora, not automatically pairable by scenario ID.
