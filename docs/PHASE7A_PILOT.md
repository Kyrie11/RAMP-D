# Phase7A pilot implementation / 验收合同

## Scope
Same 1.0.0.dev0 maintenance branch. This is an actual factual learning pilot, not the full REA architecture, no complete SC, no simulator execution, no counterfactual labels. The paper is unchanged. The existing Native verifier and proof objects are unchanged. The package API loads lazily so pure data/learning jobs do not require Native, but Native-dependent calls still fail if the actual library is absent. No fallback to floating point interval arithmetic.

## 1. Data flow (D1)
`prepare_factual_dataset.py` builds a bounded allowlist independently from official `scenario/training` and `scenario/validation` directories, reads raw records one at a time, hashes their serialized bytes, binds scenario ID, split, shard relative path and record index. Then it rereads and verifies them before transforming through the existing WOMD adapter and `scoped_factual_labels.factual`. It does not trust a user-supplied `split` field in old JSONL. Duplicate IDs, record digests and shard/index positions across the pilot fail; symlinked split folders and escaping shard paths fail. This is exact-ID/byte isolation for the **scanned pilot only**, not proof of nonoverlapping original driving logs globally. Do not use `training_20s`, TFExample or testing in this pilot. Full data scanning, source family manifests and near duplicate checks belong to later scaling. The root is assumed to be an authentic official local dataset; SHA is integrity, not authenticity. No 170 MB inventory needed. Outputs: manifest.json, summary.json, training.jsonl, validation.jsonl, one compact row per scene. Cache loads into memory only for the bounded pilot (<=1000 per split), not full training scale.

Feature schema: `[A,T,10]` actor history (center local XY, sin/cos heading relative to current ego, local velocity XY, length,width,time offset,valid); category one-hot; `[M,16]` static map edges (endpoints, midpoint, topology degree counts, kind); `[H,3]` logged ego path and query time; `[A,H,2]` targets and `[A,H]` validity, ego excluded. Current valid actors only, selection by public distance/ID, births and truncation separately counted. Coordinates are box center, **not rear axle**. Training timestamps use actual data knot offsets as the offline query grid, not online measured future behavior. The future logged ego prefix is a separate offline conditional query, not a measured control, not an online oracle. Map is static only; even historical logged signal states are not asserted visible. The 3 m approximate map sampling with corner retention and per-kind round robin is for the neural proposal only, not the proof geometry. Full lane topology, visibility, resource/task/event/commitment tokens remain missing. History validity is logged validity, not proof of ego sensor visibility. The factual pilot is a descriptive privileged-log benchmark, not closed-loop POMDP evaluation.

## 2. Model (L1)
FactualSceneEncoder: shared history MLP with valid time offsets and masked pooling, ego type marker, category, map segment encoder, gathered top-k agent-agent and agent-map attention, geometry distance bias. Neighbor lookup still computes dense distances; do not claim paper asymptotic sparse complexity. FactualJointModel caches scene features, candidate GRU separately, scene-only prior logits, shared mode embeddings, residual relative to constant velocity, predicts all currently modeled actors in each common mode. Non-autoregressive factual baseline; it does not yet implement time-unrolled causal event/response chain or awareness, full topology attention, covariance, column-mode attention, CCG/SCO. Fixed sigma=1 m per coordinate, joint mixture likelihood: for one scene sum 2D Gaussian log densities over valid actors/times then logsumexp over shared modes. Normalize batch loss by total valid actor knots. No per-actor min mode switching. Seven heads not instantiated. Zero-active batch skipped, NaN/invalid target masking tested, no gradient contribution from inactive heads. Fit uses AdamW, deterministic seeded CPU smoke (GPU exact reproducibility not asserted), gradient clip and logging. Checkpoint selected by validation joint NLL, except `--overfit-one` diagnostic uses training NLL. Reload and recompute validation; output reports include checkpoint/cache hashes and active heads. No fixed absolute ADE pass threshold on 5 scenes. The metrics are all modeled non-ego actor-knots and last-valid FDE, not official WOMD challenge metrics.

## 3. Scheduled rule overlay (specification only)
`rule_overlay.py` binds the raw scenario record hash and a lane ID from the actual map. Separate base fact, private synthetic timeline and received message projection. `generation <= effective_on < effective_off`, `generation <= issue <= receipt` when receipt exists. For this scheduled-rule profile only; effectivity can precede or follow issue/receipt. Unreceived/lost messages reveal nothing; even event ID absent. Received announced window is a payload claim, not physical ACK or resolved permission. Actual effectivity uses half-open interval. Expiry after logged horizon preserved and tagged; no invented receipt. Sidecar has all training masks false and not physically executed; do NOT combine altered rule inputs with original logged joint target. Types are prospective scenario categories, not fully defined permissions: lane closure first; later direction/clearance, speed parameter and STOP/SLOW controller transitions require actual protocol/geometry. Future 511NY/ROADWork/WZDx source priors inform category and scene selection only. Do not pair an arbitrary lane with a real report and call it same event. For real logged signal changes use separate sampled/censored signal evidence, not new authority clocks.

## 4. Acceptance (non-negotiable vs pilot performance)
- D1 mandatory: allowlist and raw hash binding; no train/validation ID/hash overlap, no future leakage, valid masks aligned, no test samples. Both splits nonempty. All skipped/rejected scenes report reasons. Pilot 5+5 goal, if data quality rejects a scene inspect reason rather than silently changing labels. A 50+10 run follows after.
- L1 software mandatory: finite loss/gradient, shared mode likelihood, padding invariance, no NaN contribution from invalid target, checkpoint replay tolerance 1e-5 on same environment. All 7 inactive heads remain uninstantiated.
- L1 diagnostic target: single-scene optimization reduces excess NLL above Gaussian floor log(2*pi) or ADE (suggest >=20% relative reduction in excess NLL/ADE, not raw NLL floor), no requirement for heldout improvement in tiny overfit. Compare modes=1 then modes=3, frozen encoder vs jointly trained. Small real validation: report CV baseline, top1 and joint-min ADE, FDE, NLL, scene/actor counts and failure cases; target improvement over CV on meaningful heldout pilot, not a hard prerequisite to develop missing heads if diagnostic works. If no improvement, inspect data and horizon; don't claim forecast superiority. On 3-8 s and larger holdout, repeat with >=3 seeds before paper claims.
- SIM-1: actual map hashes, independent physically matched landmarks >=3 noncollinear fit + >=3 independent noncollinear holdout, row-vector rigid/reflection transform, report fit and holdout max/RMSE. Suggested 0.5m preliminary tolerance, tighten based on lane width and collision clearance. This is registration preflight, not resource proof. Require independent lane matches/geometry and physical overlap, actor registry, authoritative simulator owner, clock/ACK in G3. No live run locally.
- MATH-1: existing Native gate remains a prerequisite for G1; no new certificate from learned predictions. The existing `native_multi_actor_screen`, `public_successor_binding` return conditional results and `compute_sc_inner` requires replay callbacks for transition, branch coverage, terminal. Next implement one representative complete model with full SafeTube incl dynamic/road constraints, full protocol successors from the automaton, accepting tail and rank, independent replay. No callback returns true merely on conditional screen. G1 and G3 pending.

## 5. Loss introduction / isolation order
| stage | module isolated | head | acceptance |
|---|---|---|---|
| A0 | data/feature contract only | none | provenance, frame, exact masks, perturb future no change to encoder |
| A1 | fixed CV baseline and decoder on frozen encoder; K=1 | joint | numerical NLL analytic, gradient, tiny overfit |
| A2 | encoder + joint decoder K=1 then K=3 | joint | heldout metrics, shared mode, checkpoint replay |
| B1 | exogenous event head only, synthetic protocol source | event | exact/censored time NLL, prefix invariance, event identity and scope |
| B2 | geometric footprint monitor and auxiliary head | occupancy | sampled vs swept separation, entry/stay/exit, no invalid zero, compare geometry oracle |
| B3 | observation/message adapter | observation | exact issue/receipt, missing/lost/occluded, silence only under delivery guarantee |
| B4 | closed-loop response then paired interventions | joint CF, causal | A/AA, effective A/B, common exogenous variables, traffic controller mediator, no future route privilege |
| C1 | exact finite oracle and Native complete positive replay | viability | tri-state; full finite negative proof; timeout/unknown masked |
| C2 | validated continuous margin | margin | replayed lower bound, same initial support ranking, normalization |
| C3 | conditional scheduler / protocol timing | deadline | same prefix/clock, interval and sign consistency; unresolved masked |
| D | freeze heads individually, shared encoder gradually unfrozen | all authorized | per-head denominators/gradient norms, zero active heads no step, paired ablation, no label domain mixing |

For each new head: (1) unit test target/negative examples independent of model; (2) analytic loss + mask tests; (3) overfit head on fixed frozen features; (4) independent validation; (5) introduce it into joint optimization one at a time. Compare same seed/split/checkpoint. Track per-head raw and weighted losses, valid denominator, shared-layer gradient norm and pairwise cosine; start equal normalized weights then adjust on validation, not test; optional gradient surgery only after identifying persistent interference. Do not implement dummy losses that train on zero labels. Causal loss initially separate exogenous invariance and controller mediation; observational facts not counterfactual truth. In final training report exact model/domain of each label. Math E4 positives/negative proofs scoped to model, not simulator probability.
