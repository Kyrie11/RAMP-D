# Eight supervision heads: source and validation contract (A5/3a)

Latest TeX distinguishes Q_ext (external authoritative rule), Q_act (traffic-actuated authoritative rule) and Y_int (interaction preference/response, not legal permission). Distinguish physical deployment, activation, formal effectivity, issue, receipt, and public observation. A planned road-work request can be external while clearance and barrier deployment are traffic-mediated. Sudden hazards need different physics: no guaranteed drain.

| Head | Primary source / label scope | Independent verification |
|---|---|---|
| Event | WZDx/ROADWork for weak context and realism; future SUMO/CARLA formal controller logs, scoped resources, event provenance, activation/effectivity/issue/receipt; WOMD signal transition brackets auxiliary only | externally annotated geometry and time fields, permission trace, entry/stay distinction, clearance and barrier acknowledgement, external vs traffic-actuated request tests |
| Joint | WOMD/AV2 factual path surrogate; paired responsive simulated ego intervention; no logged alternate action labels | held-out factual joint NLL/motion metrics, WOSAC realism metrics and per-scenario distribution; collision and interaction stratification |
| Occupancy | logged box center/heading/size and explicitly paired same-surface resource polygons; missing dims mask or separate weak prior; sampling only | independent geometry comparator, visual overlays, boundary/grade separation, report joint and geometry aligned denominators |
| Observation | CARLA ray casting multi-point visibility, actual sensor/detector output, protocol queue delivery/receive log, censored silence | sensor frame/time sync, manual occlusion subset, delays/drop/order, false pos/neg; no valid=observed or visibility=detection assumption |
| Viability | positive replayed SC certificate; negative only exhaustive exact finite declared class; all other cases UNKNOWN | independent strong finite planning oracle; no fair eventual exit; record class/scope and coverage |
| Margin | continuous tube-derived conservative normalized lower bound; same scope for paired ranking; not exact optimum | independently replay each bound, dimensional scale check, pair ordering only when justified; no TTC proxy as certificate |
| Deadline | exact-clock finite teacher + SC/verifier; interval labels if incomplete, same prefix/hidden histories | D_defer/D_start/T_sep+ distinct; resolve manuscript T_obs+ notation before final head; ICG interval difference [T_lo-D_hi,T_hi-D_lo] |
| Causal | paired A/A and A/B interventions under identical initial state, pre-intervention history, external mechanisms and stable keyed random draws; traffic-actuated changes allowed | A/A determinism, external request invariance, perturbation sensitivity, held-out cross-model response and real distribution comparison |

## Realistic rule mechanisms
Use actual map-anchored stop line, lane/taper geometry, signs/cones/barrier/truck place, enforce speed/route/access consistently, add detector placement upstream/downstream, check vehicle body occupancy and clearance. Follow local jurisdiction-specific temporary traffic-control standards, do not claim a universal yellow/clearance duration. Planned closure: announce/request -> no new entry -> drain -> place obstruction after clearance -> actual deployed acknowledgment; release only after removal. Sudden breakdown: obstacle can occur while occupied, response/braking and degraded feasibility; not the planned drain mechanism. Traffic-actuated alternating access: measured queues, min phase and hysteresis, all-red/drain interlock, verify current occupants clear before direction flip; ordinary courtesy in congestion stays Y_int. Preserve authoritative controller state separately from ego's information. Closed lane geometry must alter actual simulation, not just metadata. Existing executable reference model is not simulator integration.

## Public sources and acquisition
- FHWA WZDx: https://www.transportation.gov/av/data/wzdx (work-zone event extent/impact and reported times; not driver message receipts). Use official feed registry and archived snapshots where available. Preserve uncertainty and jurisdiction.
- MUTCD: https://mutcd.fhwa.dot.gov/ (temporary traffic-control devices and placements; check applicable edition and jurisdiction).
- ROADWork ICCV 2025: https://www.cs.cmu.edu/~roadwork/. Real construction visual labels, devices and path context, useful for perceptual/physical plausibility; no exact ego counterfactual or protocol clocks. Optional after reference template design.
- SUMO: https://sumo.dlr.de/docs/Simulation/Rerouter.html and https://sumo.dlr.de/docs/Simulation/Traffic_Lights.html. CARLA ScenarioRunner: https://github.com/carla-simulator/scenario_runner (match 0.9.16 branch/tag). Need explicit prop placement and trigger/acknowledgment, not only route flag.
- Waymax: https://github.com/waymo-research/waymax ; pinned installed compatible configuration. Download one WOMD v1.3.1 tf_example validation shard if not already present; log replay is not responsive; IDM primarily follows logged reference paths, not generalized interactive lane switching. Additional paired adapter later.
- WOSAC: https://waymo.com/research/the-waymo-open-sim-agents-challenge/ ; use WOMD validation scenarios and version-compatible official metrics. Not an independent source of true unexecuted-ego trajectories. Use separate environment if metric package conflicts. No separate large dataset required at present.
- CausalAgents: https://github.com/google-research/causal-agents ; optional human annotated influence labels and perturbed WOMD robustness benchmark, not ego intervention outcomes or event labels. Check ID/version coverage before use.
- TrafficSim: https://openaccess.thecvf.com/content/CVPR2021/html/Suo_TrafficSim_Learning_To_Simulate_Realistic_Multi-Agent_Behaviors_CVPR_2021_paper.html ; research method, not established downloadable dataset for this use. No dependency or download required until verified weights/code/lifetime/license and need.

## Validation before training
1. Record provenance, schema version, unit, mask, full source hashes, split/segment/map grouping, intervention and model IDs. Keep exact and weak targets separate; expose sample coverage per task and unknown fraction.
2. Independently test event semantics, geometry and timestamps, plot BEV plus timeline with issue/effective/receipt and actual deployment; inspect representative and failure cases, including grade separation, missing dims and occlusion.
3. A/A and A/B replay with explicitly keyed random sources (actor/event/time), check state/seed/version and external request invariance; do not force traffic-actuated outputs identical. Compare response distributions with held-out WOMD/AV2 and WOSAC metrics (speed, accel, angular dynamics, closest distance, collision/off-road/TTC, signal violations). Report scenario-cluster bootstrap intervals, stratified by maneuver, density, map, event; never tune on test set. Use separate stress/adversarial set and realistic calibration set.
4. Build verifier-derived heads only after absolute dynamic support, sensors and full declared scenario envelopes pass; no neural outputs become hard certificate constraints by default. Coverage of real logs cannot establish full support in reality.
